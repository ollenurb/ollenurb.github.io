The Chain Rule

We start from a simple but powerful concept that many of us can recall perfectly from high school calculus: the chain rule. \[ \frac{\partial s}{\partial t} = \frac{\partial s}{\partial u} \frac{\partial u}{\partial t} \] This formula basically tells us that the derivative of any output value \(s\) with respect to any input variable \(t\) is equivalent to the product of the rate of change of the output variable \(s\) with respect to an intermediate \(u\) and the rate of change of \(u\) itself with respect to the input variable \(t\). In plain terms, this tells us that if a value \(s\) depends directly on another variable \(u\), which in turn is depends on \(t\), then the way \(s\) changes with respect to \(t\) can be found by multiplying how \(s\) changes with \(u\) by how \(u\) changes with \(t\). It’s like tracing how a small change in \(t\) ripples through \(u\) and finally affects \(s\). This rule can then be applied repeatedly, following each intermediate variable like a domino effect, until there are no more intermediate variables and the “end” of the expression is reached. In other words, we can trace how a small change in the input ripples through each step of the computation all the way to the final output. I wrote the formula here in the most general notation on purpose. If we look closely, there are basically three things we can choose when applying the chain rule: - The output variable \(s\) to differentiate. - The input variable \(t\) we differentiate with respect to. - The intermediate variable \(u\) from which we first apply the chain rule If we carefully choose the output and input variables it is possible to differentiate subgraphs of expressions. On the other hand, choosing the intermediate variable \(u\) allow us to basically set the direction from where the chain rule will be applied (from input to output or from outputs to input).

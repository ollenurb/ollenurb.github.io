The first time they explained to me the backpropagation algorithm, it was done by simbolically derive from scratch the update rule of the weights of a neural network. Obviously, this approach is suitable only when the architecture is fairly simple, making it unfeasable for more complex and larger architectures. Common deep learning frameworks such as PyTorch, allows you to create neural networks by means of applying operations to tensors. Then, to get the numerical gradient of that network (no matter how complex) you can simply call the backward() method. This post aim to explain the basic idea of the algorithm behind that method: reverse mode automatic differentiation.

Computation Graphs

Having an efficient and automatic way to precisely compute derivatives on a computer is extremely important for many scientific areas. Let's assume for example that we have a simple function \(f(x) = 2 [\sin(x^3)^2]\) for which we want to compute its derivative. In a computer program we would represent this function straightforwardly like this: {% call code("python") %} def f(x: float) -> float: return 2 * math.sin(x**3)**2 {% endcall %} When this function is executed, it's actually evaluated in parts. The order of the evaluation of each single part is dictated directly by the availability of its inputs. For instance, the innermost function value (\(x^3\)) is evaluated first, since it depends only on the input (\(x\)), which is the only available at that point. For clarity, one can call this intermediate value \(v_0\). Then \(v_0\) is simply forwarded to the next function. Again, we give an alias to that value, for example \(v_1 = sin(v_0)\). This chain continues in the same way until the final output is reached. To make things more clear, we can write this explicitly as follows: {% call code("python") %} def f(x: float) -> float: v_0 = x**3 v_1 = sin(v_0) v_2 = v_1**2 v_3 = 2*v_2 return v_3 {% endcall %} It's not surprising that all these series of intermediate values are called the evaluation trace of a function. We could also represent the flow of computations succintly with a directed graph, where nodes are functions while edges represents input/output relationships between functions. The Chain Rule

The core idea behind automatic differentiation is also a powerful concept in math: the chain rule. \[ f'(g(x)) = f'(g(x)) \cdot g'(x) \] Even tough you will see this formula written more often in partial notation like as follows. \[ \frac{\partial f(g(x))}{\partial x} = \frac{\partial f(g(x))}{\partial g(x)}\frac{\partial g(x)}{\partial x} \] Intuitively, the chain rule tells us that the rate of change of a composite function is the rate of change of the outer function multiplied by the rate of change of the inner function. This formula can also be recursively applied in cases of nested composite function until the end of the expression. For instance, we can apply it to our example. \[ \begin{align} \frac{\partial f}{\partial x} &= \frac{\partial f}{\partial v_3}\underbrace{\frac{\partial v_3}{\partial x}}\\[.5em] &= \frac{\partial f}{\partial v_3}\frac{\partial v_3}{\partial v_2}\underbrace{\frac{\partial v_2}{\partial x}}\\[.5em] &= \frac{\partial f}{\partial v_3}\frac{\partial v_3}{\partial v_2}\frac{\partial v_2}{\partial v_1}\underbrace{\frac{\partial v_1}{\partial x}}\\[.5em] &= \frac{\partial f}{\partial v_3}\frac{\partial v_3}{\partial v_2}\frac{\partial v_2}{\partial v_1}\frac{\partial v_1}{\partial v_0}\frac{\partial v_0}{\partial x}\\[.5em] \end{align} \] I have put underbraces to indicate terms where the chain rule can be re-applied for clarity. The trick here is to treat \(v_i\) as a function of \(v_{i-1}\) since (in this particular case) it's its direct input. If you want, you can expand the entire expression by substituting all the values so that it's written only in term of the input variable \(x\). In that way it should be more clear how the formula works and how it has been applied here.

If we look closely at the expanded formula, we evaluate these product from two different starting point. This decision basically determines the two types of automatic differentiation: forward and backward mode.

Forward Mode

If we start from the rightmost term \(\frac{\partial v_0}{\partial x}\) in the chain rule expansion, we can compute that derivative immediately, because the only input whose \(v_0\) depends on is \(x\).
